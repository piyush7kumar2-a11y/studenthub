C & Pointers Question #1

What is the output of the following C pointer arithmetic snippet?

int arr[] = {10, 20, 30, 40};
int *p = arr;
printf("%d", *(p + 2));
Show Answer & Explanation
Output: 30
Explanation: p initially points to arr[0] (value 10). *(p + 2) offsets by 2 integer memory widths, accessing arr[2] which is 30.
Java Collections Question #2

What is the primary difference between HashMap and Hashtable in Java?

Show Answer & Explanation
Key Differences:
1. Synchronization: HashMap is non-synchronized (faster, not thread-safe), whereas Hashtable is synchronized.
2. Null Values: HashMap allows one null key and multiple null values, whereas Hashtable does not permit any null keys or values.
DSA & Algorithms Question #3

How do you detect a cycle in a Singly Linked List in O(N) time and O(1) space?

Show Answer & Explanation
Floyd's Cycle-Finding Algorithm (Tortoise and Hare):
Initialize two pointers, slow and fast, at the head. In each iteration, advance slow by 1 step and fast by 2 steps. If fast and slow ever meet, a cycle exists. If fast reaches null, there is no cycle.
